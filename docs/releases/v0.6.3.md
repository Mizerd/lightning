# Lightning 0.6.3

The first release with official **Windows x86_64** packages alongside the
existing Linux formats, plus fixes to Windows video playback and Linux touchpad
scrolling. Every shipped build uses only the Rust Matrix backend.

## Highlights

- Windows x86_64 packages are now part of the main release: a portable ZIP, an
  MSI installer, and a setup EXE installer.
- Windows video playback is fixed: the packaged client now ships the FFmpeg
  multimedia backend and pins it, so inline videos decode continuously instead
  of freezing after the first frames.
- Linux touchpad timeline scrolling is smoother and no longer resists upward
  scrolling or gets pulled back down while history loads.
- Every shipped binary uses only the Rust Matrix backend — the HTTP/mock
  development backends are not compiled into release builds and cannot be
  selected or silently fall back to.
- GIF provider configuration is embedded at build time, so the GIF browser
  works with no setup on a fresh install.
- The application icon is regenerated from a high-resolution source, so the
  taskbar, window switcher, and installer icons stay crisp.

## Windows video playback

Inline videos on Windows previously showed a few frames and then froze. The
Windows package shipped only the Windows Media Foundation backend, which stalls
after the initial buffered frames. Lightning now builds and bundles the Qt
Multimedia FFmpeg backend (`ffmpegmediaplugin`) and its runtime libraries, and
selects it explicitly, so videos play through to the end. Packaging validation
fails the build if the FFmpeg runtime is missing, so a Windows package can never
ship without a working video backend.

The bundled FFmpeg is an LGPL build with native decoders; see the verification
section for the licensing note.

## Linux touchpad scrolling

Scrolling the timeline up with a touchpad could jitter and snap the viewport
back down as avatars, media, and link previews finished loading. The touchpad
scroll path now keeps its scroll anchor current on every gesture, so late
content growth above the reader can no longer pull the view down. Scrolling up
stays where you put it; scrolling to the bottom still re-engages follow-latest.

## Rust-only backend

Release builds compile only the official Matrix Rust SDK backend. The HTTP and
mock development backends are excluded from the shipped binary, `--backend=http`
and `--mock` are rejected, and there is no silent fallback. `matrix-client
--build-info` reports the backend and build invariants for verification.

- Setup EXE installer (`-setup.exe`) — per-user install.

## Windows signing notice

**The Windows packages are currently unsigned.**

- Windows may show an "Unknown publisher" prompt, and Microsoft Defender
  SmartScreen may warn before running the installer or executable.
- The warning does not by itself mean the file is unsafe. Download Lightning
  only from the official GitLab release, and verify the SHA-256 checksum below.
- Do not disable SmartScreen, antivirus, or Windows security to run Lightning.
- Code signing is not yet configured; these packages are provided unsigned.

## Verification

- Every asset is listed in `SHA256SUMS`. Verify a download with
  `sha256sum -c SHA256SUMS` on Linux, or `CertUtil -hashfile <file> SHA256` on
  Windows, and compare against the published value.
- All assets are built from the exact `v0.6.3` application commit; the full
  source commit is recorded in each binary's `--build-info` output.
- No GIF provider key setup is required — configuration is embedded at build
  time and never printed by `--build-info` or `--gif-status`.
- The bundled Windows FFmpeg is an LGPL build (native decoders, no GPL or
  nonfree components).

## Known limitations

- The Windows packages are unsigned (see above).
- Per-room notification modes remain device-local, not synchronized server push
  rules.
- End-to-end encryption cannot recover historical messages whose keys were
  never backed up or shared.
