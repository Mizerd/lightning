# Lightning 0.8.2

A feature release with one fix at the front of it: **a Lightning participant no
longer drops out of a call every five minutes.**

## The five-minute call dropout

Reported from real use, and the symptom was the diagnosis. A Lightning user in a
MatrixRTC call vanished after exactly five minutes and came back — while the
others could still *hear* them, and they could hear nobody.

Every client reads an RTC membership's deadline as `created_ts + expires`, and a
refresh deliberately preserves `created_ts`, or the oldest-membership focus
selection reorders under everyone. So re-publishing the same constant `expires`
republished the same **absolute instant**: the membership died a fixed period
after the join however often it was refreshed. The 60-second re-publish loop had
been running correctly the whole time, writing a value that could not extend
anything.

That also explains the lopsidedness, which is the part that misled. Peers aged
the membership out and rotated media keys *without* that user, so their own media
kept flowing to an SFU that had never disconnected them — still audible — while
the new key was one they had never received.

The deadline is now computed as `(now - created) + period`, saturating both ways.

**NOT live-validated.** Proving it needs a real call held past five minutes with
another client, and that has not been done.

## Stickers and custom emoji

MSC2545 sticker packs, in all three places the spec puts them: your own
(`im.ponies.user_emotes`), a room's (`im.ponies.room_emotes`), and packs
subscribed from other rooms (`im.ponies.emote_rooms`). A dedicated browser in the
picker, pack creation, and save-to-pack so a sticker someone else sent can be
kept and re-sent from your own collection. Sent stickers render as a bare image —
no bubble, no filename, no file card.

Two deliberate omissions: there is no pack **editor** yet (creation works,
renaming and removing entries does not), and custom emoji are not yet inline in
message bodies, because the HTML sanitiser allows no `<img>` and such a message
would render blank rather than wrong.

## A crop dialog for every display image, and JPEG XL

One crop dialog now sits behind avatars, profile banners, room avatars and Space
avatars. It selects **the region that will be visible**, rather than showing the
visible region and cropping inside it — which is the correction that makes a wide
image fit a banner the way you chose.

JPEG XL is recognised at every decode boundary. Both forms are handled, with the
container signature tested before the bare codestream, since the container begins
with bytes the bare test would misread.

## Profiles

Bios (an MSC4133 extended profile field — an unset field answers 404, which means
*unset*, not *unsupported*), your own avatar changeable from settings, a
rooms-in-common list, and a contributor badge. Presence is a corner bubble on the
avatar rather than a line of text, and unknown presence renders **nothing** —
never a fabricated "offline".

## The call stage

Controls moved to the top of the stage and participant bubbles to the top-left
opposite them, so the picture gets the rest. In full screen the chrome and the
mouse pointer retire after a few seconds of a **still** pointer — wherever it is
resting — and any movement brings both back.

That last rule took four attempts, and the failures are worth recording. Two
versions keyed on the pointer's *position*, which is correct on two monitors
(tabbing away moves the pointer out of the window) and never fires for anyone
with one. The version after that hid the chrome and was then woken by its own
hide: retiring changes what sits under the pointer, Qt re-delivers a hover event
at the same position, and the handler counted that as movement. Every test of it
passed because none of them had a pointer at all.

## Other fixes

- Images could stick loading forever until a restart — no retry was wired on any
  of the three media surfaces.
- Hiding an image now persists across sessions, account-scoped, with sign-out
  separated from the user's own "show all".
- The login screen always offers a route to accounts already on the device.
- The GIF picker's Saved tab was blank on Qt 6.8 — a proxy model must define
  `roleNames()` itself, or a delegate with required properties builds zero rows
  while the count stays correct.
- Dismissing a link preview leaves a way to load it again, rather than hiding it
  for good. Automatic loading remains **off by default**: Lightning fetches a
  preview itself rather than through the homeserver's proxy, so loading one
  automatically would hand your IP address and read timing to a host the sender
  chose. The switch is in Settings → Privacy & security.
- Spell checking in the composer, editor shortcuts working in threads as well as
  the main composer, larger inline and reaction emoji, custom font import.
- A Space-scoped People filter, and a rail folder that deletes itself once
  emptied.

## Security

Sticker packs live in room state that any member can write, and MSC2545 permits a
pack entry to omit its `mimetype` — so the declared type could not carry the rule
that untrusted SVG is never rendered. The refusal now happens at the media choke
point, on the **shape** of the bytes rather than a list of spellings: every raster
format this client accepts opens with binary magic, so an image-class payload
beginning with `<` (after BOM and whitespace) or with gzip is refused, and every
thumbnail and avatar path inherits it.

## Validation

Rust tests 239 passed / 0 failed / 4 ignored. Rust-backend CTest 172/172. Non-Rust
CTest 170/171, the one failure being `timeline-pane-qml`, a load-sensitive suite
that passes in isolation and passed in the Rust tree in the same run. The
no-media-engine configuration — the one the Linux package jobs build — compiles
clean across every target.

**Live validation.** The profile popover, banners, the People filter and the call
chrome were exercised on a real desktop. Everything else in this release is
implemented and covered by automated tests but **NOT TESTED** against a live
homeserver: stickers, JPEG XL, the crop dialog, bios, spell checking, the tray
badge, and above all the five-minute dropout fix.
